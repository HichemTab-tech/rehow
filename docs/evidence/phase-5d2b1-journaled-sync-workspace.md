# Phase 5D2B1 journaled sync Workspace evidence

The internal core primitive consumes only an opaque, clean `remoteFastForward` classification. It revalidates the complete local sync plan and staged tree, reads every staged blob through the validation mirror, recomputes its Git object ID, and builds a bounded sorted current/incoming effect set.

Changed files use exact-revision replacement, new files use absent-only publication, and removed files move to operation-bound `.rehow/trash` paths. The existing recovery journal supplies durable before-images and replay. A new top-level Attachment root and new Category/Attachment directories are created in operation-private staging, durably bound to operation/path/device/inode, then moved no-replace into the Workspace. Failed-sync cleanup quarantines only that exact identity; pre-existing empty directories and racing replacements are preserved. Existing directories must be owned by the effective user and not group/world writable. A fresh confined scan must exactly reproduce the validated remote tree. Active Git objects, index, refs, config, reflogs, and `HEAD` remain untouched.

The end-to-end sync test covers manifest and Guide replacement, `.gitignore` creation, Guide and whole-Category trash removal, exact trash bytes, remote-tree reopening, authority redaction, and unchanged `HEAD`. Focused adversarial tests cover Category and Attachment replacement races, failed Category and Attachment-root creation cleanup, and preservation of a pre-existing empty Attachment directory. The complete workspace gate passes 405 core tests with 2 intentional network/performance ignores, 18 error-contract tests, 13 protocol tests, the public-API/trybuild suite, 11 unknown-YAML tests, 22 desktop tests, and the MCP smoke test. Formatting, strict all-target/all-feature workspace Clippy, bootstrap validation, and whitespace checks pass. The reused Security Reviewer reports PASS with no blocker/high/medium finding.

This is deliberately crate-private and is not a complete synchronization transaction. Phase 5D2B2 must durably install a sync intent before invoking it, then replay append-only object installation and expected-state index/direct-ref publication. No adapter can invoke the partial primitive.
