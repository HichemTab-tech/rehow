# Task Packet: Phase 6E2C MCP Guide tested approval

- **Objective:** Allow MCP-assisted content to become Tested only after exact-revision native user approval through the standalone server.
- **Required reasoning level:** high implementation; xhigh security review.
- **Prerequisites:** Accepted Phase 3O verification/native approval, Phase 6E1 approval foundation, accepted Phase 6E2A–B execution/cancellation patterns, ADRs 0015, 0026, 0040–0044.
- **Allowed files or subsystem:** `crates/rehow-core/src/{application,storage}.rs`, `crates/rehow-core/src/storage/recovery.rs`, `apps/desktop/src-tauri/src/lib.rs` only for exhaustive shared-error mapping, `crates/rehow-mcp/`, Phase 6 MCP/architecture/security/testing/development docs, this packet/evidence/ADR, and `PROGRESS.md` after the feature commit.
- **Relevant specifications and ADRs:** `docs/content-model.md` verification section, `docs/mcp-spec.md`, `docs/architecture.md`, `docs/threat-model.md`, ADRs 0015, 0040, 0041, and 0044.
- **Exact required behavior:** `guide_tested_plan` validates one exact issue-free, unarchived, ready, not-already-Tested Guide and returns a non-secret preview; it issues a token only with startup write authority and a trusted helper. `guide_mark_tested` accepts only handle+token, consumes it, obtains Tested native approval, refreshes/rechecks every bound fact, and invokes the core exact-revision verification-hash mutation with cancellation at the journal boundary. Denial returns an explicit unchanged result.
- **Important states and edge cases:** Read-only/helper-unavailable preview; already Tested; Draft/Stale/mismatched declared-Tested; archived; missing/empty/duplicate Steps; malformed ID/revision/token; duplicate Guide ID; denial; expiry; replay; wrong Workspace; cancellation before/during/after the helper; external edit/move/archive; busy recovery; committed-refresh-required; unsafe storage.
- **Security constraints:** No client consent assertion, generic status/hash/time/path/effect authority, broad capability requirement, arbitrary helper, shell, network, credentials, or mutation before approval. Bind the token to exact identity/revision/path/Category and Workspace capability. Recalculate readiness/hash from the exact current bytes under the writer lock. Logs/errors omit body, commands, paths, and verification hash.
- **Tests to add or update:** Exact 32-tool schema; core preview/readiness and cancellation-boundary tests; approved transition with verification/effective status; already-Tested no-token preview; read-only/helper-unavailable preview; native denial byte identity; replay/scope/expiry/stale/archived/unready cases; real JSON-RPC cancellation without writes; desktop exhaustive shared-error mapping; existing verification vectors.
- **Commands to run:** Focused core/MCP/desktop tests and strict Clippy while iterating; before commit run full Cargo tests/Clippy/format, installed local JS checks/tests/build, verification vectors, bootstrap, and whitespace gates.
- **Required reviews and artifacts:** One correction-focused Security Reviewer after implementation; update MCP/security/testing evidence. Reuse the already-smoked packaged helper unless operation-specific native behavior changes.
- **Explicit non-goals:** Generic `guide_change_status`; client-supplied tested state/hash/time; Guide delete/rename/move/content edits; Attachment mutation; broad/destructive/Git authority; remote MCP; Node/pnpm installation or switching.
- **Definition of done:** Narrow schemas, exact preview, sealed native approval, exact revalidation, cancellation/replay/denial/stale tests, verification vectors, full gate, independent security PASS, accurate evidence/progress, and signed checkpoints.
- **Expected commit boundary:** One signed planning checkpoint, one signed implementation/docs checkpoint, and a progress-only checkpoint only if needed; Orchestrator owns commits.
- **Conditions requiring escalation:** Consent can be forged or replayed, a client can select Tested metadata, readiness/hash are not recalculated from exact bytes, cancellation can begin a new mutation after being observed, helper identity is absent, or a genuine human checkpoint occurs.
