# Task Packet: fixed credential proxy and sealed helper resources

- **Objective:** Invoke only the launch-retained HTTPS credential helper through a fixed, bounded, non-logging protocol proxy and descriptor-mounted, Workspace-free, networkless resources.
- **Required reasoning level:** xhigh.
- **Prerequisites:** Signed Phase 5D3D1 checkpoint `41a2549`; accepted helper/config provenance.
- **Allowed files or subsystem:** Core credential proxy/provenance/resources and tests, dedicated proxy binary, helper build preparation, native launch state, ADR 0025, Git architecture/threat/testing/development docs, this packet/evidence, and `PROGRESS.md`.
- **Relevant specifications and ADRs:** ADR 0025 Sections 5D3D1–5D3D2; `docs/architecture.md` Git process policy; `docs/threat-model.md` credential, subprocess, disclosure, and confinement controls.
- **Exact required behavior:** A dedicated binary accepts exactly `get`, `store`, or `erase`; requires a parent-bound HTTPS host and closed helper kind; parses a bounded Git credential record; rejects duplicate/unknown/malformed/control-bearing fields and secrets on `get`; directly invokes only the fixed descriptor-mounted helper with the exact operation (or exact `gh auth git-credential <operation>` argv), a cleared environment, bounded time/output, no shell, and no diagnostics; validates helper output before forwarding it. Native launch retains a separately captured proxy capability, and preparation clones only proxy/helper descriptors for fixed Bubblewrap mounts.
- **Important states and edge cases:** Missing/unsafe proxy/helper, wrong helper kind or host, extra argv, malformed/missing terminator, wrong protocol/host, duplicate scalar fields, bounded repeatable fields, secret-bearing `get`, oversized input/output, helper failure/signal/timeout, hostile output, and empty valid lookup.
- **Security constraints:** No Workspace/repository/config mount, network, repository-selected helper, PATH lookup, shell, prompt, stderr forwarding, logs, `Debug` secret/path exposure, IPC, credential persistence, or remote connection. Close-on-exec changes occur only in the setup child.
- **Tests to add or update:** Input/output grammar and exact limits; hostile argv/env/field corpus; direct command construction and empty real-helper lookup; proxy provenance and redaction; missing/unsafe resource matrix; fixed descriptor mounts in a networkless sandbox with `/workspace` absent; packaged dev/release helper preparation; native-only retention.
- **Commands to run:** Focused proxy/resource/native tests; standalone invalid invocation; `pnpm check`; `pnpm test`; strict all-Workspace Clippy; production and optimized Tauri builds; bootstrap/whitespace checks.
- **Required reviews and artifacts:** One reused Security Reviewer only after the complete proxy/resource gate; evidence records credential canaries and exact confinement.
- **Explicit non-goals:** Passing these resources to Git network children; authenticated HTTPS clone/sync/push; mounting secret-service or `gh` config; renderer/MCP visibility; credential storage; UI; new dependency.
- **Definition of done:** The proxy and resource capability are packaged and native-held, protocol/argv/output are bounded and closed, one networkless invocation path is proven, secrets have no app-visible channel, full gates and Security Review pass, and the next operation gate is explicit.
- **Expected commit boundary:** Proxy/resources/native/tests/docs in one signed commit; verified progress ledger may follow separately.
- **Conditions requiring escalation:** Need for arbitrary helper argv/path, shell, repository config, Workspace mount, network, credential persistence/disclosure, new dependency, or unresolved security finding.
