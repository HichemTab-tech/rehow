# Task Packet: Phase 6E2D3 MCP managed Attachment discovery and metadata add

- **Objective:** Let MCP safely discover and register an undeclared regular file already managed under one Guide's Attachment directory without accepting any path or bytes.
- **Required reasoning level:** high implementation; xhigh Security Reviewer acceptance.
- **Prerequisites:** Accepted native Attachment import/removal, Phase 6 write capability, ADRs 0016/0017/0038/0045/0046, and ADR 0049.
- **Allowed files or subsystem:** `crates/rehow-core/src/{application.rs,storage.rs,storage/**,protocol*.rs}` only as needed; `crates/rehow-mcp/src/server.rs`; Phase 6/content/threat/testing docs, evidence, and progress. No desktop UI/Tauri command.
- **Relevant specifications and ADRs:** `docs/content-model.md` Attachment/inventory limits; `docs/mcp-spec.md`; `docs/threat-model.md`; ADRs 0016, 0017, 0038, 0045, 0046, and 0049.
- **Exact required behavior:** `attachment_candidates_list` takes handle/Guide/cursor/limit and returns exact Guide revision plus paginated `{candidateToken,name,sizeBytes}` records from only `attachments/<GuideId>/`. Core retains private exact file authority; server cache is process-local, 256-entry bounded, five-minute, scope/revision bound. `attachment_metadata_add` takes handle/Guide/revision/token/title, requires write, consumes token, generates ID/path/hash/size/time in core, changes Guide metadata recoverably, leaves file bytes/name unchanged, preserves unknowns, and stales Tested.
- **Important states and edge cases:** missing/archived Guide or directory; empty discovery; declared candidate; 256 Attachment limit; duplicate content; invalid/hostile filename; symlink/hardlink/FIFO/socket/device; oversize/aggregate/count limit; file replacement/change before or during hashing/apply; stale Guide revision; token expiry/replay/eviction/wrong Workspace/Guide/revision; read-only call; unsafe Guide presentation; no-op impossible; committed refresh failure.
- **Security constraints:** No caller path, relative path, bytes, hash, size, ID, timestamp, media type, status, YAML, shell, process, network, Git, broad capability, or consent assertion. Descriptor-relative no-follow only; exact file identity/content revalidation under the writer lock; token/debug/errors are redacted; candidate name is labeled untrusted. Never delete, rename, move, copy, open externally, render, or execute a candidate.
- **Tests to add or update:** Core discovery confinement/filtering/bounds/redaction and metadata-add success/preservation/stale/duplicate/limit/race cases; MCP exact closed schemas, 45-tool list, pagination, read/write capability, token lifetime/scope/replay, no path/hash/bytes canary, successful add, and stable errors. Temporary Workspaces only.
- **Commands to run:** Focused core/MCP tests plus strict affected-crate Clippy while iterating; then once: `pnpm check`, `pnpm test`, `pnpm build`, `cargo fmt --all --check`, strict all-Workspace/all-target/all-feature Clippy, Bootstrap, and whitespace checks.
- **Required reviews and artifacts:** `docs/evidence/phase-6e2d3-mcp-attachment-metadata-add.md`; one Security Reviewer after focused gates; no visual review because no UI changes.
- **Explicit non-goals:** Host-file import, upload/download, arbitrary relative path, cross-Guide move, byte replacement, filename rename, media type, rendering/open/reveal/export, bulk adoption, desktop surface, new dependency.
- **Definition of done:** ADR behavior and all refusal states are implemented; tool count/schema/redaction are exact; relevant focused/full gates pass; Security Reviewer has no blocker/high/medium finding; signed implementation and progress checkpoints exist.
- **Expected commit boundary:** One planning/toolchain checkpoint, one implementation/docs/evidence checkpoint, then a progress-ledger checkpoint. Orchestrator owns commits.
- **Conditions requiring escalation:** Any need for caller path/byte/hash authority, file mutation/deletion, unbounded retained state, a new dependency, unknown-metadata loss, inability to revalidate the exact candidate, or unresolved race that can silently bind metadata to different bytes.
