# Task Packet: Phase 4E search interaction completion

- **Objective:** Complete Phase 4 search retrieval with bounded plain-text excerpts/highlights, explicit status scopes including archived Guides, responsive keyboard behavior, and renderer-latency/visual evidence.
- **Required reasoning level:** high; this closes a product phase and changes the core/native/UI search contract.
- **Prerequisites:** Signed checkpoints `c53378d`, `a4ca4e3`, and `f2edc2a`; ADRs 0004 and 0018; approved Reference Desk direction.
- **Allowed files or subsystem:** `rehow-core` search only; desktop Tauri search payload/tests; desktop React search state/results/styles/tests; Phase 4E packet/evidence, search/design/testing docs where reality changes, and `PROGRESS.md`.
- **Relevant specifications and ADRs:** Product search requirements/budgets; architecture search flow; ADRs 0004/0018; design-direction search/results, no-results, keyboard, narrow, and screenshot rules; testing search/performance matrix.
- **Exact required behavior:** Search returns ordered Guide IDs, matched-field reasons, a bounded plain-text excerpt, and bounded Unicode-scalar highlight spans—never HTML. The UI safely renders `<mark>` from text segments, offers Active/Tested/Draft/Stale/Archived/All status scopes, excludes Archived by default, passes the closed scope explicitly for core filtering before ranking/result caps, retains Arrow/Enter/Escape navigation, and offers actionable clear/search-archived empty states. The debounce must leave room for the 50 ms backend and 100 ms visible budgets.
- **Important states and edge cases:** Empty/whitespace query, cross-field terms, quoted phrase, exact command/path/error, Unicode, overlapping/repeated highlights, long body windowing, stale response after query/scope change, unknown Guide ID, empty scope, archived-only search, 100-result cap, long excerpt, and narrow/200% layout.
- **Security constraints:** Excerpts derive only from already loaded canonical Guide text, are length/count bounded, cross IPC as plain text plus integers, and render through React text nodes; no HTML, file paths beyond already searchable documented content, filesystem/process/network/write authority, or raw query syntax is introduced.
- **Tests to add or update:** Core deterministic excerpt field/window/span/limit/Unicode tests and pre-cap status-scope regression; native payload shape/closed-scope tests; UI scope/filter/segment validation/stale-order tests; 5,000-Guide backend gates remain green; renderer transformation and production-visible latency evidence; keyboard/accessibility/static guideline and representative screenshot review.
- **Commands to run:** Focused Rust/Vitest tests; `pnpm check`; Cargo format and locked all-target/all-feature Clippy/tests; `pnpm test`, `pnpm build`, `pnpm tauri:build`; bootstrap, contract, whitespace, production performance and screenshot review.
- **Explicit non-goals:** Fuzzy/semantic search, saved searches, Favorites, custom scopes, a new search dependency, persistent index bytes, arbitrary query language, related/duplicate recommendations, or changing ranking boosts.
- **Definition of done:** Search rows explain why they matched with safe highlighted excerpts; every required status/archived scope works; keyboard/narrow/accessibility behavior remains usable; backend and visible budgets pass with recorded evidence; all gates and one combined review pass.
- **Expected commit boundary:** Core/native/UI contract, interactions, tests, evidence, and aligned docs form one signed Phase 4 completion checkpoint; verified progress follows.
- **Conditions requiring escalation:** Unicode spans cannot be made unambiguous, payload limits regress, renderer work exceeds budget, scope semantics conflict with lifecycle rules, or representative native visual testing cannot be performed without new external authority.
