# Task Packet: Automatic external-change reconciliation

- **Objective:** Detect external managed Workspace changes automatically and trigger the existing canonical reconciliation without trusting event paths or discarding dirty edits.
- **Required reasoning level:** high; filesystem observation and renderer/native concurrency cross a security boundary.
- **Prerequisites:** Signed Phase 4C checkpoint `a4ca4e3`; ADRs 0009, 0018, and 0019; argument-free manual refresh.
- **Allowed files or subsystem:** core watcher/storage modules and manifest/lockfile; desktop Tauri adapter/capability; `App.tsx`, focused tests/styles if required; ADR 0019, this packet/evidence, and `PROGRESS.md`.
- **Relevant specifications and ADRs:** External-change/search sections of product, architecture, testing, and threat-model docs; ADRs 0009, 0018, 0019.
- **Exact required behavior:** Watch only retained descriptor-backed root/managed directories; coalesce events; emit no paths/content; clean UI automatically invokes argument-free canonical refresh; dirty/busy UI defers and explains; refocus reconciles after background activity; successful refresh rebuilds watches; watch failure becomes visible degraded state; manual refresh always works.
- **Important states and edge cases:** Atomic-save bursts, add/remove/rename, new Category/Attachment directories, internal-write echo, malformed external file, failed refresh, watch setup/rebuild error, stale event from a previously open Workspace, dirty Guide/details/Category/create forms, event during refresh, refocus recovery, and Workspace switch.
- **Security constraints:** Events are hints only; no event path crosses core/Tauri/IPC; no arbitrary root, recursive caller-path traversal, symlink following, shell/process/network authority, write authority, or content logging; only exact Workspace ID/native-session correlation and existing confined refresh.
- **Dependency decision:** Exact `notify 8.2.0`, default features disabled, in core only. Exact crate source documents CC0-1.0 and Rust 1.77; resolved `notify-types 2.1.0` raises the effective floor to Rust 1.85, below Rehow's 1.98. Official documentation covers Linux inotify and delivery limitations. It replaces unsafe custom inotify code; no debouncer/runtime/serialization dependency is added.
- **Tests to add or update:** Temporary-Workspace managed edit and burst coalescing; degraded/error signaling seam; descriptor-watch set rebuild/new directory; ignored irrelevant nested Git activity; payload contains no paths; stale Workspace-ID rejection and dirty/busy deferral helper; capability permits listen/unlisten only; existing manual refresh/failure-retention tests remain green.
- **Commands to run:** Focused core/desktop/Vitest tests; contract/type/lint checks; full locked Workspace tests and Clippy; production web/native builds; bootstrap/whitespace; dependency tree/license/source audit.
- **Explicit non-goals:** Precise per-file event interpretation, event-driven targeted reads, background content mutation, persistent cache, arbitrary polling, Git watching semantics, cross-platform storage, snippets/highlights/scopes, or resolving dirty conflicts automatically.
- **Definition of done:** External managed edits update clean sessions automatically; dirty work is preserved with actionable pending state; loss/degradation has refocus/manual recovery; all reads remain canonical/confined; no event path crosses IPC; tests and builds pass; independent review has no blocker/high/medium finding.
- **Expected commit boundary:** ADR/dependency, core watcher, desktop event adapter/UI behavior, tests, and evidence form one signed feature checkpoint; verified progress follows.
- **Conditions requiring escalation:** A watcher requires absolute caller-path authority, event content becomes necessary, dirty work could be replaced, watch teardown can deadlock, dependency audit fails, or automatic recovery requires frequent production-scale full scans.
