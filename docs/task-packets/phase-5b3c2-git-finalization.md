# Task Packet: Validated clone Git finalization

- **Objective:** Turn the marker-bound, content-complete clone destination into an exact usable shallow Git repository by copying only validated staging objects and publishing canonical metadata with a completion seal last.
- **Required reasoning level:** high.
- **Prerequisites:** Signed checkpoint `48d5ee8`; accepted ADR 0023; retained destination and staging capabilities; canonical C1 Workspace rescan.
- **Allowed files or subsystem:** Core Git/storage/recovery staging modules, ADR 0023, this packet, focused evidence, and progress bookkeeping. Native lifecycle wiring may follow only after the core boundary passes. No React or MCP changes.
- **Relevant specifications and ADRs:** ADRs 0009, 0022, and 0023; Git/confinement/recovery sections of architecture, testing strategy, and threat model.
- **Exact required behavior:** Revalidate the exact remote commit/tree and C1 Workspace; enumerate a bounded canonical staging object inventory through no-follow descriptors; stream-copy each required object/pack file to the private destination object store with stable source state, digest, `0600`, fsync, and no-replace publication; install exact shallow boundary, canonical secret-free `origin` config, local and remote-tracking refs using expected-absent compare-and-verify semantics, and `HEAD`; publish an operation/plan-bound completion seal last; reopen through confined Git status and require the expected branch with no content changes.
- **Important states and edge cases:** SHA-1/SHA-256, nested branch names, multiple packs, pack/index pairing, optional promisor markers, shallow boundary, source mutation, destination collision, symlink/hardlink/special file, interrupted object copy, interrupted metadata publication, exact retry, marker/seal mismatch, foreign residue, and completion replay.
- **Security constraints:** No checkout, worktree rewrite, merge, reset, hooks, filters, aliases, shell, credential helper, prompt, arbitrary ref/path, renderer-supplied OID, or deletion. URL must be the already validated secret-free canonical URL. Existing unknown state is preserved and refused. The completion seal is append-only so provenance is never overwritten.
- **Tests to add or update:** Successful real SHA-1 clone finalization and confined status; exact interruption replay across object and metadata boundaries; source/destination race refusal; pack grammar/pairing and aggregate limits; nested branch refs; marker/seal mismatch; no overwrite; no worktree change; SHA-256 where host Git supports it.
- **Commands to run:** Focused clone/finalization tests, core formatting, all-target/all-feature Clippy with warnings denied, one full core gate, bootstrap validation, and whitespace checks.
- **Required reviews and artifacts:** Focused evidence and one reused Security Reviewer only after the complete authority-bearing core slice is green.
- **Explicit non-goals:** React onboarding controls, SSH, credential helpers, ordinary commit/pull/push/sync, cleanup/quarantine, MCP, history expansion, or checkout.
- **Definition of done:** The native-held validated clone can be finalized into a confined usable shallow repository, every interruption is safely replayed or refused, focused/full gates and security review pass, and a signed checkpoint exists.
- **Expected commit boundary:** Core staging/object inventory, destination finalization state machine, tests, ADR/evidence, then native lifecycle connection if the same boundary stays reviewable.
- **Conditions requiring escalation:** Need to overwrite/delete unknown Git state, accept arbitrary Git paths/config, weaken source stability or no-follow confinement, expose URL/OID/path to renderer IPC, or execute checkout/credentials.
