# Task Packet: Safe Git commit plan and candidate construction

- **Objective:** Implement ADR 0024's 5C1 read-only manual-commit plan and private candidate-object construction without changing the active repository or Workspace.
- **Required reasoning level:** Xhigh architecture/security implementation.
- **Prerequisites:** Signed anonymous-clone checkpoint `efc9fcf`; accepted ADRs 0006, 0021–0024; retained direct repository capability and canonical Workspace scanner.
- **Allowed files or subsystem:** `crates/rehow-core/src/git.rs` plus narrowly required private storage readers, focused core tests/fixtures, ADR 0024 evidence, and progress. No native/React/MCP changes.
- **Relevant specifications and ADRs:** Git sections of product, architecture, threat model, testing strategy, ADRs 0006, 0021, 0022, 0023, and 0024.
- **Exact required behavior:** Validate a bounded safe one-line message and exact local identity; require writable issue-free current Workspace, direct safe SHA-1/SHA-256 repository, canonical symbolic branch with exactly one direct loose or packed target representation (or exact absence for unborn), the exhaustive ADR marker/lock absence set, checksum-valid bounded v2/v3 index with only cache-tree extension and semantic equality to `HEAD`; read the bounded byte-path `HEAD` tree, batch-prove every preserved object's presence/mode-compatible type, and validate its absent-or-compatible prior managed snapshot; classify the exact current managed inventory; preserve all unrelated `HEAD` entries and refuse exact/ancestor/descendant collisions when a newly claimed managed path was not previously managed; construct exact blob/tree/unsigned-commit objects in a core-created template-free private XDG scaffold through config-free filter-free plumbing without `mktree --missing`; independently verify candidate IDs; compute only an informational config-isolated unrelated-status count; enforce the ADR's time/output/file/object/per-operation/aggregate-quarantine limits; refuse an unchanged managed tree; return a crate-public opaque redacted plan exposing only token/branch/effect counts/unrelated count. Bind every ADR 0024 plan field including loose/packed ref representation and change no active repository/Workspace byte.
- **Important states and edge cases:** Unborn branch; direct loose or packed nested branch; indirect/symbolic, malformed, duplicate loose-plus-packed, and duplicate packed target refs; detached/invalid `HEAD`; absent/dirty/unmerged/sparse/split/extended index; every enumerated operation/lock marker; missing/duplicate/unsafe identity; malformed/absent prior managed snapshot; missing/promisor/corrupt/type-mismatched preserved objects; managed create/update/delete; unrelated tracked file/tree at the exact path, ancestor, or descendant of a newly claimed managed path; unrelated tracked modifications/deletions and untracked hostile byte names; SHA-1/SHA-256 disagreement; empty/no-op managed delta; staging interruption/collision/quota; external HEAD/index/loose-ref/packed-refs/config/Workspace races.
- **Security constraints:** Root-owned fixed Git/Bubblewrap only; argv without shell; cleared environment/config/network; no worktree bind for candidate construction; only the exact active object store as a read-only synthetic alternate; `hash-object --no-filters`; `mktree` must prove object presence; no hooks, attributes, signing, editor, pager, helper, credential, repository alternate, arbitrary ref, path IPC, active Git write, cleanup deletion, or content logging. Enforce every numeric ADR bound before/while consuming input.
- **Tests to add or update:** Exact/one-over message, identity, HEAD listing, index, process, staging, and aggregate-quarantine limits; hostile config/hooks/filter/attributes/signing canaries; all enumerated index/operation/lock states; valid unborn and direct loose/packed parented candidates; indirect/malformed/duplicate target-ref refusal; managed delta and unrelated preservation; exact/ancestor/descendant tracked collision refusal; absent/valid/malformed prior snapshot; missing/promisor/corrupt/type-mismatched preserved objects; SHA-1/SHA-256 parity/disagreement; candidate object recomputation; cancellation/replacement quarantine; plan redaction/Debug; deterministic HEAD/index/loose-ref/packed-refs/config/Workspace races; source audit proving no active mutation call.
- **Commands to run:** Focused commit-plan tests while coding; Cargo formatting; locked core all-target/all-feature Clippy with warnings denied; one full core gate; bootstrap validation; whitespace check; one Security Reviewer at the completed 5C1 checkpoint.
- **Explicit non-goals:** Installing objects, writing index/ref/reflog, native/React commands, confirmation, cancellation UI, signing, global identity, network, credentials, push/pull/fetch/sync, merge, cleanup, or MCP.
- **Definition of done:** Core can produce and verify the complete opaque candidate plan for every accepted state; no active content or Git byte changes; adversarial/focused/full gates and Security Reviewer pass; evidence and signed checkpoint exist.
- **Expected commit boundary:** One 5C1 core/evidence commit, followed by a progress ledger commit if needed.
- **Conditions requiring escalation:** Any need for active repository mutation, unreviewed dependency, global/out-of-Workspace config read, index-extension acceptance, repository-selected program, ambiguous deletion ownership, signing, network, or weakened bound.
